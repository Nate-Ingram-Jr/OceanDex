# OceanDex Roadmap

## Now
- Sightings forum: owner/admin edit and delete, image uploads, and public feed.
- Add post comments and replies so sightings become discussions.
- Add report/flag controls for moderation.

## Next
- User profiles with posted sightings, saved creatures, and scan history.
- Search and filters for sightings by tag, date, and popularity.
- Map view for sightings and community-reported locations.

## Later
- Follow creatures and get notifications for new sightings.
- Multi-photo uploads for a single sighting.
- Verified sighting badges for trusted users or moderators.
- PWA install support for mobile-first use.

## Long-Term
- AI-assisted identification from sighting photos.
- Social sharing cards for species pages and sightings.
- Deeper moderation tools and analytics for conservation trends.
